Политика конфиденциальности «Такт»

Дата обновления: 14 октября 2026 года.

«Такт» — расширение Chrome для учёта времени. Оно работает без отдельного аккаунта и без сервера разработчика.

Какие данные обрабатываются

  • Записи времени: название задачи, начало и окончание, признак оплачиваемости, ссылка на задачу (если она добавлена), технический идентификатор записи, время последнего изменения и отметка удаления.
  • Когда пользователь нажимает Start, расширение один раз читает URL и заголовок активной вкладки. Если вкладка похожа на задачу Jira, расширение извлекает ключ задачи, добавляет его к названию таймера и сохраняет ссылку на задачу. Адреса и заголовки остальных вкладок не сохраняются.
  • При импорте JSON расширение обрабатывает выбранный пользователем файл локально. При экспорте оно создаёт локальный файл JSON или CSV.

Где хранятся данные и кому они передаются

Все записи хранятся в chrome.storage.local на устройстве пользователя. Активные таймеры и до 100 последних завершённых записей, а также отметки удаления могут дополнительно храниться в chrome.storage.sync. Если пользователь включил синхронизацию Chrome, эти данные могут передаваться между его устройствами средствами Google Chrome и обрабатываться Google в рамках этой функции. Более старая история, не вошедшая в лимит storage.sync, остаётся только на устройстве.

Разработчик не получает записи, не отправляет их на свой сервер, не использует аналитику и рекламу и не продаёт данные. Пользователь может сам передать экспортированный файл выбранному им получателю; расширение не загружает такой файл автоматически.

Управление данными

Записи можно редактировать, удалять, импортировать и экспортировать в интерфейсе расширения. Удалённые записи сохраняются как отметки удаления, чтобы удаление могло синхронизироваться между устройствами. Удаление расширения очищает его локальное хранилище в Chrome; данные, уже сохранённые в Chrome Sync, управляются настройками синхронизации Google Chrome.

Разрешения

  • storage — сохранение записей и синхронизация через Chrome.
  • alarms — отложенный повтор синхронизации после изменений или ошибки.
  • activeTab — чтение URL и заголовка текущей вкладки после нажатия Start для распознавания задачи Jira.

Использование информации, полученной через API Google, соответствует политике данных пользователей Chrome Web Store, включая требования ограниченного использования. Данные применяются только для работы описанных функций расширения.

По вопросам о расширении можно обратиться к разработчику через страницу «Такт» в Chrome Web Store.
