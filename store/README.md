# Публикация «Такт» в Chrome Web Store

## Готовые материалы

- ZIP для загрузки: `.output/takt-1.0.0-chrome.zip` (создаётся командой `npm run zip`).
- Значок 128×128: `public/icon/128.png` (уже входит в ZIP).
- Промоизображение 440×280: `store/takt-promo-440x280.png`.
- Основной набор скриншотов 1280×800, в порядке загрузки: `store/01-timers.png`, `store/02-history.png`, `store/03-manual.png`, `store/04-edit.png`.
- Дополнительные скриншоты Jira: `store/05-jira-timer.png` и `store/06-jira-link.png`. Они показывают запуск таймера из задачи и ссылку в истории.
- Политика в расширении: `public/privacy.html`, доступна по ссылке внизу интерфейса.
- Текст политики для общедоступной ссылки: `PRIVACY.md`.

Все изображения уже находятся в `store/` и загружаются отдельно в карточку Chrome Web Store; в ZIP расширения они не входят. Магазин принимает от одного до пяти скриншотов. Основной набор из четырёх файлов образует последовательность 01–04; если хотите показать Jira, выберите один или оба дополнительных файла вместо части основного набора. Перед загрузкой проверьте изображения на личные названия задач и ссылки. Размер скриншота должен быть 1280×800 или 640×400 пикселей, без полей и скруглённых углов.

## Текст карточки

**Краткое описание:** Учёт времени по нескольким задачам: таймеры, ручные записи, история и синхронизация Chrome.

**Полное описание:**

Такт помогает вести учёт времени по нескольким задачам одновременно. Запускайте и останавливайте таймеры, добавляйте записи вручную, отмечайте оплачиваемое время и просматривайте историю по дням и неделям. При запуске таймера с открытой задачей Jira расширение может добавить ключ задачи, взять её тему из заголовка вкладки и сохранить ссылку.

Записи сохраняются локально. Активные таймеры и часть недавней истории могут синхронизироваться через Chrome Sync, если он включён. Всю историю можно экспортировать в JSON или CSV; JSON также можно импортировать. Отдельный аккаунт и сервер разработчика не требуются.

## Поля Privacy practices

**Единственная цель:** Учёт времени и истории задач пользователя.

**Обоснование разрешений:**

- `storage`: сохраняет таймеры и историю локально, а часть записей — в Chrome Sync.
- `alarms`: планирует повторную отправку в Chrome Sync после изменений или ошибки.
- `activeTab`: после нажатия Start читает адрес и заголовок активной вкладки, чтобы распознать задачу Jira, сохранить её ключ и ссылку и при необходимости заполнить название таймера.

Расширение не исполняет удалённый код, не отправляет данные разработчику, не использует рекламу и аналитику. В декларации данных укажите обработку введённых пользователем названий задач, времени, ссылок на задачи и URL/заголовка активной вкладки при запуске таймера. Не отмечайте «данные не обрабатываются»: локальное хранение и Chrome Sync тоже требуют раскрытия.

## Ссылка на политику

Политика внутри ZIP полезна пользователю, но поле **Privacy policy URL** требует общедоступную HTTPS-ссылку. Если репозиторий `somefix/takt` публичный и `PRIVACY.md` опубликован в ветке `master`, используйте `https://github.com/somefix/takt/blob/master/PRIVACY.md`. Иначе разместите тот же файл в публичном репозитории, GitHub Gist или на GitHub Pages. Собственный сервер не нужен. Перед отправкой проверьте ссылку в приватном окне браузера.

## Загрузка

1. Запустите `npm test`, `npm run typecheck`, `npm run format:check` и `npm run zip`.
2. В [панели разработчика Chrome Web Store](https://chrome.google.com/webstore/devconsole) нажмите **Add new item** и загрузите `.output/takt-1.0.0-chrome.zip`.
3. Заполните карточку, загрузите `store/takt-promo-440x280.png` и выбранные скриншоты (не более пяти), укажите публичную ссылку на политику и заполните Privacy practices. Выберите видимость Public или Unlisted.
4. Нажмите **Submit for review**. Для следующего выпуска увеличьте `version` в `wxt.config.ts` и соберите новый ZIP.

Перед установкой магазинной версии вместо распакованной экспортируйте JSON из старой версии и импортируйте его в новую: разные ID расширения означают разные хранилища.
